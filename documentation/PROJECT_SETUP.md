# HIMALAYA CLIMATE SECURITY

## Project Setup Guide

### 1. Project Requirements

Before running the project, install:

- Python 3.10 or above
- Git
- Visual Studio Code
- pip (Python Package Manager)

### 2. Clone the Repository

Open your terminal and run:

git clone https://github.com/bhargavismiley314-cpu/HIMALAYA_CLIMATE_SECURITY.git

### 3. Open Project Folder

cd HIMALAYA_CLIMATE_SECURITY

### 4. Create Virtual Environment

python -m venv .venv

### 5. Activate Virtual Environment

Windows:

.venv\Scripts\activate

### 6. Install Dependencies

pip install -r requirements.txt

### 7. Run Automated Tests

python -m pytest tests/ -v

### 8. Project Development

Open the project in Visual Studio Code and explore the backend and climate_engine modules.

### 9. Important Note

This project is currently under development. 
Some features may require additional configuration.
